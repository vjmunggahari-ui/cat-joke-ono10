One joke about cats, a single line under 200 characters — the cat knocks the phone off the table while holding eye contact, and the punchline lands on the human, not the cat.

Entry for the make.fun competition [The One-Line Cat Joke That Lands](https://make.fun/competitions/u-aldy998-the-one-line-cat-joke-that-lands-a7b18262).

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

Writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` and verifies it back (exact match, 1–200 chars, not only whitespace).
